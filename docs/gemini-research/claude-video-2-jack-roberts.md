## 1. Executive Summary

**Claude Video 2.0** (`claude-video-studio`), created by **Jack Roberts**, is an open-source motion design skill for Claude Code that generates studio-grade motion graphics and explainer videos from code. 

Built on **HyperFrames** and **GSAP**, it addresses the most persistent flaw in AI-generated motion graphics: the **"generic AI drift"** (where models default to dark backgrounds, neon purple gradients, and centered glowing text). 

Jack solves this with an opinionated, production-tested architecture:
1. **The 21-Style Gallery:** An interactive local visual gallery where every look is demonstrated with a real rendered video, flippable to show how it integrates with real user footage ("With Media").
2. **The 5 Production Hacks:** Concrete constraints (locking a style spec first, using real design references over adjectives, writing briefs strictly in numbers, single-clock loops, and checking frames rather than code).
3. **Automated Mechanical Quality Gates:** Before full rendering, the agent extracts 3 keyframe stills (~0.6s after shot transitions) for user approval; after rendering, it runs automated Python linters checking **pacing** (no dead gaps $> 1\text{s}$, no flash cuts $< 0.3\text{s}$) and **pixel-perfect loop continuity**.

## 3. Deep Dive: Key Technical Capabilities & Innovations

### 3.1 The "5 Hacks" for Professional Motion Graphics

Jack Roberts codifies why AI agents typically generate amateurish motion and enforces 5 strict engineering habits:

| Hack | Principle | Implementation Rule |
| :--- | :--- | :--- |
| **1. Pick One Style First** | Eliminates aesthetic drift between shots. | The chosen `STYLE.md` fixes the exact hex palette, font weights, easing curves, and ban list. No colors may be typed anywhere else. |
| **2. References Beat Adjectives** | "Sleek and modern" produces garbage; a real frame produces perfection. | Instructs creators to pull reference frames from Savee, Godly, Mobbin, or Apple/Linear launch films, and describe *how* they were built (e.g. *"masked text reveal, slow camera push, 1.2s hold"*). |
| **3. Write the Brief in Numbers** | Ambiguous descriptions lead to hallucinated pacing. | Length in exact seconds, colors in hex, easing in GSAP numbers (`power3.out` over 0.55s), max 6 words per card, one accent color. |
| **4. Loops: One Clock** | Seamless loops require mathematical continuity. | Drives all motion from a single normalized clock (`STUDIO.play(t)`). `loop_check.py` diffs the RGB pixels between the final frame and the first frame to guarantee zero jump. |
| **5. Check Frames, Not Code** | Valid syntax does not equal good aesthetics. | Extracts 3 stills 0.6s after transitions. Runs `pacing_check.py` to flag dead holds ($> 1\text{s}$) or unreadable flash elements ($< 0.3\text{s}$). |

### 3.2 The Universal Ban List
Every project generated by the skill enforces a non-negotiable ban list:
- ❌ No hue-shifting gradients (e.g. purple-to-cyan).
- ❌ No glow, bloom, or lens flares.
- ❌ No linear easing on anything the eye tracks.
- ❌ No centered-everything layouts.
- ❌ No more than one accent color.
- ❌ Nothing scales up from zero (start at scale 0.6 to 0.9 with opacity).

### 3.3 The 21 Production-Grade Style Catalog (`styles/`)

Jack packages 21 complete styles, each with its own `STYLE.md` and working reference piece:

| Style Archetype | Best For | Easing & Motion Profile |
| :--- | :--- | :--- |
| **`explainer-diagram`** | How something works, pipelines, systems, data flow. | Dot grid, Switzer type, rounded orthogonal wires, pulses with 220px comet packets (`power2.inOut`). |
| **`swiss-kinetic`** | High-energy tech announcements, typography stings. | Bold asymmetrical grids, heavy tracking, fast snap-ins (`expo.out`, 0.4s), strict monochrome + red accent. |
| **`editor-ui` / `motion-app-ui`** | SaaS feature demos, developer tooling. | 2.5D window perspectives, dark graphite panels, active cursors, glowing selection pills. |
| **`paper-world` / `paper-cut`** | Creative agency intros, tactile storytelling. | Layered craft textures, subtle shadow elevations, organic deceleration curves. |
| **`blueprint` / `technical`** | Hardware, engineering architectures, schematics. | Navy/cyan gridlines, technical callout crosshairs, step-animated line reveals. |
| **`data-story`** | Metrics, benchmarks, analytics dashboards. | Spring-animated counters (`back.out(1.8)`), SVG area chart fills, tabular numbers. |

### 3.4 Automated Pacing & Loop Verification Scripts

#### A. Pacing Checker (`pacing_check.py`)
Analyzes the rendered video frames to detect dead time:
- Computes frame-to-frame pixel difference ($\Delta P$).
- Flags any stretch $> 1.0\text{s}$ where $\Delta P \approx 0$ (stagnant video causing viewer drop-off).
- Flags any visual element appearing and disappearing in $< 0.3\text{s}$ (subliminal flashes that cannot be read).

#### B. Loop Checker (`loop_check.py`)
- Extracts frame $0$ and frame $N$ (final frame).
- Performs an exact Euclidean pixel difference: $\text{diff} = \sum |P_0 - P_N|$.
- Verifies that the transition from frame $N$ back to frame $0$ does not exceed the normal inter-frame velocity.

## 5. Actionable Takeaways for AeroEdits

### 🟢 What We Should Adopt

1. **Port the 21 Style Specifications into AeroEdits Styles:**
   - Jack Roberts’ 21 styles represent the most polished collection of HyperFrames motion design in existence.
   - We should map these styles directly into AeroEdits’ Style System (`styles/`):
     - `explainer-diagram` $\to$ native pipeline/system explainer preset.
     - `swiss-kinetic` $\to$ bold typographic short-form preset.
     - `editor-ui` $\to$ software launch and feature demo preset.
2. **The "3 Stills at $+0.6\text{s}$" Quality Gate (`frame_render`):**
   - In AeroEdits’ `frame_render` tool, adopt Jack’s timing rule: when sampling keyframes across a graphic, **sample at $t = \text{transition} + 0.6\text{s}$**, capturing the frame after entrance animations have settled.
3. **Automated Pacing Linter in `graphic_check`:**
   - Incorporate `pacing_check.py` rules into AeroEdits:
     - Flag graphics that remain completely static on screen for longer than 1.5s without camera drift or packet flow.
     - Flag cards with text that disappear in less than 0.5s per word.
4. **The Universal Ban List in Agent Prompts:**
   - Embed Jack’s ban list (no hue-shifting gradients, no bloom/lens flares, no scaling from zero, max 6 words per card) into AeroEdits' `mcp/skill/graphics.md`.
5. **Seamless Loop Verification for Backgrounds:**
   - For looping background motion graphics in shorts or talk sections, adopt `loop_check.py`'s pixel-diff check to guarantee flawless loops.

### 🔴 What We Refuse / Avoid

1. **Do NOT force a browser-based gallery server (`python3 gallery.py`):**
   - Jack spins up a Python HTTP server on port 127.0.0.1 to let users pick styles. AeroEdits is already a native desktop application; our Style picker belongs in the native desktop Inspector panel with embedded video thumbnail previews.
2. **Do NOT restrict graphics to standalone clips:**
   - Jack’s skill focuses on standalone intros, ads, and loops. In AeroEdits, graphics are layered over real human footage, anchored to spoken transcript words (`atWord`), and responsive to split-screen layout slots (`data-mode="split"`).
